What This Site Is

The one-sentence version: I commit HTML into _deploy/ on main, and one GitHub Actions workflow uploads that folder to GitHub Pages exactly as it is.

Two Kinds of Page

Hub pages

  • Home, Projects, Walkthroughs, About, each case study's index
  • Card grids styled by the shared hub.css
  • Nav injected by site-chrome.js from a few <meta> tags
  • Edited by hand

Content pages

  • Every docs/<project>/*.html except the index
  • MkDocs-Material layout: sidebar, contents, previous/next
  • Written in Markdown in _src/
  • Never edited by hand: the next build overwrites them
One brand file. Every page and deck reads its colours from assets/theme.css.

From Push to Live Page

push to main ──► build job ─────────────────────► deploy job
(_deploy/** or    checkout                         actions/deploy-pages
 the workflow)    configure-pages                  run summary with links
                  upload _deploy/ as the artifact
  • Pull requests build, never publish: Pages has one live deployment per repo
  • Path-gated: a README edit does not deploy
  • Actions pinned to commit SHAs
Permissions: contents: read, pages: write, id-token: write. No secrets at all.

The sidebar is baked into every page. Add or reorder one page and every page in the set changes, so the build always regenerates the whole set.

Decks Built From the Case Studies

The docs-to-deck skill reads a case study's pages and builds a reveal.js deck from a JSON plan. The first question is always who it is for:

Deck type Audience Shape
overview Recruiters, hiring managers Short, outcome-first, little code
deep-dive Engineers, technical interviews Architecture, decisions, trade-offs
talk A meetup or team talk Story-led: problem to lessons
Checked by rendering. screenshot_deck.py renders every slide in Playwright and measures overflow, because a slide that spills over still passes every structural check.

Trade-offs and Lessons

No build step gives

  • Deployment cannot break a page
  • No generator or theme upgrades
  • A one-job workflow with no secrets

It costs

  • Committed HTML makes bigger diffs
  • One new page rewrites the whole set
  • Checks only help if I run them
From the clean-up: a disabled step can still be load-bearing. The template's deploy failed if a generated data file was missing, even though the step that generated it was switched off.
