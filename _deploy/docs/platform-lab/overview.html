    Overview

    A full platform stack on an 8 GB laptop, deployed from Git by Argo CD. Work in progress.

    Platform Lab is one repository for a real home platform: a Kubernetes cluster that Argo CD deploys entirely from Git, with GitHub Actions runners inside the cluster. The challenge is to run the tools a platform team actually uses (GitOps, ingress, CI runners, a container registry, Prometheus and Grafana, AWX, Backstage, and a KVM hypervisor for VM images) on one 8 GB laptop, with no cloud bill. It is also how I practise for the Kubernetes certifications: the cluster I study on is the platform itself.

    Status: in progress. The kind cluster and Argo CD are running and syncing from GitHub through a GitHub App, after a DNS search-domain clash that broke TLS to GitHub was found and fixed. The core platform (Traefik, Metrics Server, RBAC and the Headlamp cluster UI) deploys from Git, and every UI opens with no port-forward. In-cluster runners for this repo and the Packer pipeline are next, then hardening. See the roadmap and problems log.

    Principles

    • Git is the source of truth. After a one-script bootstrap, nothing is installed by hand. Changing the platform means opening a commit, and rolling back means git revert.
    • No throwaway tutorials. No sample apps in sprint namespaces: every component is a real part of the platform.
    • Capacity first. An always-on core plus one heavy profile at a time, each with explicit requests and limits.
    • Secrets never go in Git.
    • Built by hand first. Every step is in a written guide with no scripts: what to do, why, and how to check it worked. The bootstrap scripts exist, but only as a shortcut once the manual path is understood.
    • Every security control is tested. A control without a test that proves it blocks something doesn't count.
