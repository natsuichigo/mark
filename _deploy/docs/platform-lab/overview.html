    Overview

    A home platform built sprint by sprint and run like production. Work in progress.

    Platform Lab is one repository for building a reusable home platform: a local Kubernetes platform, the automation around it, and eventually Terraform-managed infrastructure and an image factory. It is also how I practise for the Kubernetes certifications, so each sprint ends with something running that I can work against.

    Status: in progress. Sprint 0 (workstation and repository) is done. Sprint 1, the first Kubernetes platform, is underway. Later sprints are on the roadmap.

    Principles

    • One product. Everything belongs in the platform-lab repository, so the work doesn't fragment across many small repos.
    • Every commit contributes to the platform. No throwaway tutorials.
    • Capacity first. Heavy services wait until the lab has the resources to run them properly.
